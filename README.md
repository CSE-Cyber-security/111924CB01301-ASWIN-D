## 🚀 How to Run Any Week's Task

### Clone the Repository
```bash
git clone https://github.com/CSE-Cyber-security/Cyber-Week-1-Assingment.git
cd Cyber-Week-1-Assingment
```

### Switch to a Specific Week's Branch

- **For Week 1:**
  ```bash
  git checkout week--01
  python src/asset_inventory.py
  ```

- **For Week 2:**
  ```bash
  git checkout week--02
  python factorial.py
  ```

- **For Week 3:**
  ```bash
  git checkout week--03
  ```
