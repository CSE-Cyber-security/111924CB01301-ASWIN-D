## How to Run

### Clone the Repository
```bash
git clone https://github.com/CSE-Cyber-security/Cyber-Weekly-Assignments.git
cd Cyber-Weekly-Assignments
```

### Switch to a Week

- **Week 1:**
  ```bash

  python src/asset_inventory.py
  ```

- **Week 2:**
  ```bash
  git checkout week--02
  python factorial.py
  ```

- **Week 3:**
  ```bash
  git checkout week--03
  python fibonacci.py
  ```
